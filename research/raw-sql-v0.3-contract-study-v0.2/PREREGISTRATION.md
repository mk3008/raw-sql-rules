# Preregistration: replacement Contract 3 effect study

Status: pre-launch.

This study tests whether showing Contract 3 changes final behavior of
`gpt-5.6-terra` at medium reasoning. Control and Treatment receive the same
fixture, task specification, Scope, author Default Requirements, model, and
workspace-write runtime. Treatment alone receives the unchanged Contract 3
text. Candidate-visible materials do not include evaluator details, v0.1,
research terminology, or operational guidance.

The official plan is five scenarios (A--E), two arms, and two independent
fresh repositories per arm: 20 launches. Every candidate repository is an
actual initialized Git repository outside this source worktree. Its isolation
is verified before and during the candidate run. Each evaluator result records
required behavior, arbitrary runtime SQL syntax prevention, tenant integrity,
no over-blocking, and no confirmed relevant final defect. Candidate self-report
is not a Primary criterion.

No input text, evaluator criterion, fixture, candidate profile, execution
order, or replacement selection may change after the first official launch.
Calibration and isolation preflight are not official effect data.
