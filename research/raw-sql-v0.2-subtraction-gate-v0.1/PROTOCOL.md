# Raw SQL v0.2 subtraction gate protocol

## Question

Given the same frozen v0.2 Contracts and Requirements, does removing the legacy
non-Requirement operational/HOW bundle materially worsen objective outcome or a
materially useful process action?

## Arms and delivery

Reduced receives the frozen PR #33 `raw-sql-rules.md` and only the minimal
pointer in `packets/reduced-AGENTS.md`. Guided receives byte-identical fixture,
prompt, and v0.2 file plus `packets/guided-AGENTS.md`. No observer material is
candidate-visible. The runner records source manifests that must match after
excluding `AGENTS.md` and the Guided-only bundle difference.

## Candidate execution

There are exactly four serial slots in `execution-order.json`, all using
`gpt-5.6-terra`, medium reasoning, `danger-full-access`, and approval `never`.
Each is a fresh local one-commit repository with no remote. A lifecycle event
pair (`thread.started` and `turn.started`) consumes a slot; no consumed slot is
retried. A pre-turn setup error may be repaired only if frozen candidate-visible
bytes and experimental semantics remain unchanged; it must be recorded and the
study stops if that is not true.

## Calibration and invalidity

Before official launch, the evaluator must reject a known-bad Task A unsafe-sort
variant and a known-bad Task B precision-loss variant while accepting the known
good variants. Failure, arm/prompt mismatch, unavailable real DB boundary,
missing lifecycle evidence, candidate environment mismatch, or a non-reachable
Task A merge boundary is `INVALID_OR_INSENSITIVE`; no product conclusion follows.

## Outcomes

Primary is objective final application/database quality only. Candidate
self-testing, review, or Rules conformance is not itself a Primary point.
Secondary observations are recorded separately from event streams, final source,
and repository state.

Classify once after four turns: `SUBTRACTION_SUPPORTED`,
`GUIDANCE_OUTCOME_VALUE_OBSERVED`, `GUIDANCE_PROCESS_ONLY_DIFFERENCE`,
`NO_PRACTICAL_SEPARATION_OBSERVED`, or `INVALID_OR_INSENSITIVE`, using the
stopping criteria in `FREEZE.md`. A bundle-level no-difference result does not
prove that every individual G1--G5 sentence has zero isolated effect.
